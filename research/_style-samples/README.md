# HTML 簡報風格範例

三個範例用**同一份內容**（股債配置、Brinson、相關性、2022、台灣集中度），只差在捲動動態。風格依 `DESIGN.md`：奶油色畫布、膠囊與圓形、橘色軌道線、淡色浮水印大字、墨黑按鈕。

| 檔案 | 名稱 | 捲動時會發生什麼 |
|---|---|---|
| `sample-a-orbit.html` | Orbit 軌道 | 一條橘色軌道線隨捲動畫出來，串起每張圓形插圖；圓形插圖旋轉放大進場、衛星按鈕彈出；浮水印大字左右視差；膠囊長條與數字跑動 |
| `sample-b-stack.html` | Stadium Stack 堆疊 | 開場插圖從膠囊展開成整個畫面；之後每一頁是一張大圓角卡片，下一張滑上來時前一張縮小變暗、疊在後面；插圖視差 |
| `sample-c-track.html` | Editorial Track 橫向 | 往下滑時頁面向右翻（橫向雜誌）；圓形插圖從小圓點擴張顯露、外圈橘線畫出；文字逐行升起；第 2 頁有可拖動的相關係數 ρ 拉桿 |

- 已是單一 HTML（插圖內嵌）。字型與 KaTeX 從 CDN 載入，需連網
- `src/` 是原始碼（引用 `../../../asset/`）；修改後執行：
  `py -I tools/inline_assets.py research/_style-samples/src/<檔名>.html research/_style-samples/<檔名>.html`
- 範例 C 的拉桿使用示意假設（股 60%／債 40%、波動 20%／6%），頁面上已標註非歷史數據
- 有系統「減少動態效果」設定時，三個範例都會改成靜態版
