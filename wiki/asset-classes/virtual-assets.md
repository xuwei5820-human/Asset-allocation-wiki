# 虛擬資產（Virtual Assets / Crypto）

**一句話定義**：以區塊鏈為基礎發行的數位資產，不依賴中央機構發行或管理（[[sources/sfi-investing-risk-management-2026]]）。

## 主要類型（[[sources/sfi-investing-risk-management-2026]]）
- 加密貨幣：比特幣（BTC）、以太幣（ETH）
- 穩定幣：與法幣掛鉤（如 USDT）
- NFT：數位資產所有權憑證
- DeFi 代幣

## 核心特性
- 去中心化、全球 24/7 交易
- 高度波動：單日漲跌 20–50% 不罕見（[[sources/sfi-investing-risk-management-2026]]，未附出處，依幣種差異很大）

## 風險清單（[[sources/sfi-investing-risk-management-2026]]）
| 類型 | 說明 |
|---|---|
| 價格波動 | 受情緒、政策、大戶操作影響 |
| 流動性 | 小型幣種在極端行情可能難以賣出 |
| 市場操控 | 監管較弱，可能有拉盤、砸盤 |
| 平台倒閉 | 例：FTX，用戶資產可能拿不回來 |
| 錢包安全 | 私鑰遺失或被盜，資產永久無法找回 |
| 詐騙 | 假平台、釣魚網站、假空投 → [[taiwan/anti-fraud]] |

## 在資產配置中的位置
- 簡報建議：先有投資經驗，再用「可承受損失的閒置資金」少量嘗試
- 若要納入，比較適合放在[[strategies/core-satellite|衛星部位]]，並在 [[my-portfolio/ips|IPS]] 寫下比例上限
- 與股票的相關性、長期預期報酬的依據 → 待 ingest 研究
